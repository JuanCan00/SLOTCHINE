## Descripción

**SLOTCHINE** fue creado como espacio base para recopilar software y documentación técnica (manuales de operación y configuración) relacionados con distintos dispositivos de máquinas de casino y de suerte y azar.

Actualmente el repositorio contiene la configuración inicial, la licencia **Apache 2.0** y archivos de verificación de commits colaborativos realizados durante la puesta en marcha del flujo de trabajo en GitHub.
